# FM350 Backup

Полная копия памяти модема Fibocom FM350-GL прямо на роутере с OpenWrt: страница в LuCI, дамп на флешку или сразу на компьютер. **Программа только читает модем.** Команд записи и приёмов обхода защиты в ней нет.

Неофициальная программа, с Fibocom и MediaTek не связана. Используете на свой риск, гарантий нет, см. `LICENSE`.

## Что нужно

- Роутер с OpenWrt 23.05–25.12, LuCI и интернетом. Установщику нужно 20 МБ свободного места, а если Python уже стоит, хватит 3 МБ.
- Модем FM350-GL на USB.
- Файл DA из пакета прошивки вашего модема, обычно `download_agent/DA_BR.bin`. В программе его нет.

## Сколько занимает

| Что | Размер |
|---|---|
| Сама программа | 1,4 МБ |
| Файл DA | 0,4 МБ |
| Python и то, что ему нужно | около 13 МБ |
| Всего, без сжатия | около 15 МБ |

На роутерах со сжатой файловой системой получается меньше: на Cudy WBR3000UAX заняло около 7 МБ. Во время дампа программе нужно ещё до 45 МБ оперативной памяти. После `fm350-uninstall` место освобождается, Python удаляется, если его поставила сама программа.

## Установка

На роутере по SSH:

```sh
wget -O- https://github.com/Rombaldo/luci-app-fm350backup/releases/latest/download/install.sh | sh
```

Страница появится в LuCI: Modem, FM350 Backup. Там нажмите «Загрузить файл DA» и выберите файл, это можно сделать с любого устройства с браузером. Программа проверит, что это настоящий DA.

## Дамп

1. Выберите, куда сохранить, и нажмите «Снять полный дамп». Это занимает примерно 3 минуты на компьютер и 7–8 минут на флешку.
2. Модем на это время пропадёт из сети.
3. После дампа выключите роутер из розетки на 10 секунд: иначе модем останется в режиме загрузчика. Если модем в USB-переходнике, достаточно выдернуть и вставить переходник.

**Не выкладывайте дампы в открытый доступ:** в них IMEI, серийный номер и настройки вашего модема.

## Удаление

```sh
fm350-uninstall
```

Убирает программу, файлы DA, а также Python и libusb, если их не было до установки. Драйверы USB и `block-mount` остаются: они маленькие, а снимать их на работающем роутере опасно. Дампы на флешке остаются. Оставить файлы DA: `fm350-uninstall --keep-da`.

## Что проверено

| | Установка | Настоящий дамп |
|---|---|---|
| OpenWrt 25.12.6, aarch64, Huasifei WH3000 Pro, модем во внутреннем слоте | да | да |
| То же, модем в USB-переходнике | да | да |
| OpenWrt 25.12.5, aarch64, Cudy WBR3000UAX | да | нет, модем не подключали |
| OpenWrt 25.12.6, 24.10.8, 23.05.6, x86-64, контейнер | да | нет, там нет модема |

Другие роутеры и другие модемы не проверялись. Программа не обходит защиту: если модем не принимает файл DA или на нём включён SLA, она сообщит об этом и остановится, модем при этом не меняется.

Журнал сбоев `expdb` может читаться не до конца: на проверенном модеме так же было и в SP Flash Tool. Недочитанное заполняется байтами FF, программа об этом пишет.

Записывать дамп обратно эта программа не умеет. Восстановление дампа на модеме этой программой не проверялось.

## Разработка

`scripts/test.sh` проверяет код без роутера, `scripts/build-release.py` собирает архив в `dist/release/`. При каждом изменении GitHub Actions запускает тесты и установку на OpenWrt, а по тегу `vX.Y.Z` собирает черновик релиза.
